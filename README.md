1. **비즈니스 모델 맞춤형 2-Track 광고 최적화**

   - **🛒 Track B (온라인 즉시결제 + 상담 병행 6종)**: `명함(#748490137)`, `스티커(#738722850)`, `전단지(#907344096)`, `리뷰스티커(#11905267494)`, `서비스스티커(#11917122413)`, `취급주의스티커(#12350470478)` — 중지(OFF)되어 있던 `스티커제작(#202018026)` 광고그룹 복구 및 `서비스스티커` 수동 키워드 광고 편입

3. **전화상담 · 계좌입금 매출 간편 기록부 & 통합 실질 ROAS 산출**
   - 쿠팡을 보고 전화/카톡 문의 후 계좌입금한 주문을 기록하여 온라인 매출 + 계좌입금 매출 합산 통합 ROAS 자동 계산
